# Mission Bio

Mission Bio is a South San Francisco single-cell multi-omics company. Its Tapestri Platform
simultaneously resolves DNA variants, copy number, protein and RNA signal from the same individual
cell, for oncology, precision medicine, and cell-and-gene-therapy research.

Mission Bio publishes **no public REST, GraphQL, MCP, A2A or event API** (verified 2026-08-01 against
every host). Its developer surface is a first-party Python analysis stack — Mosaic, `missionbio.h5`,
`missionbio.demultiplex`, `missionbio.plotting`, `missionbio.annotation`, `missionbio.filter`,
`missionbio.config` and a `tapestri` CLI — distributed as conda packages on the `missionbio` Anaconda
channel and documented at [missionbio.github.io](https://missionbio.github.io/). Data is produced by
the Tapestri Pipeline as HDF5 `.h5` files and managed through the Tapestri Portal.
